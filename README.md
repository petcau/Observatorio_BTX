# Observatorio_SNCT2026

## Páginas de pesquisadores

- `cientistas.html` — painel geral do BTX, com pesquisadoras e pesquisadores;
- `cientistas-baianas.html` — recorte feminino do Observatório, com o título **Conheça as cientistas baianas** e filtragem dos registros marcados com sexo feminino.

As duas páginas reutilizam a mesma base e os mesmos componentes. O recorte é aplicado no carregamento dos dados, evitando que a mudança de título apresente perfis incompatíveis com a proposta editorial.
